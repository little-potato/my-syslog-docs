    Management¶

    Public Fields¶

    Field Value Explanation
    timestamp ISO 8601 timestamp format The date and time the event has been triggered.
    team_id Integer Splashtop Team ID.
    category String Splashtop events category.
    kind String Splashtop events kind under specific category.
    action add or update or delete The event operating action type in the event.
    account String The user account that initiated the specific event.
    source_agent browser or client or streamer or openapi or scim or system or deployment The origin client of the specific event.
    source_address String IPv4 format. The origin IP address in the specific event.
    source_version String The origin client version in the specific event.
    source_os String The origin operating system in the the event.
    source_name String The origin client name in the specific event.
    target_agent browser or client or streamer The target device type in the event.
    target_address String IPv4 format. The target IP address in the event.
    target_version String The target agent version in the event.
    target_os String The target agent platform in the event
    target_name String The target device name in the event.
    target_account String The target user account in the event.
    result String Success or failure of the event.
    extra_result String The reason of a failed event. This field is present only when the result is failure. See the extra_result values table under each kind.

    Endpoint Policy¶

    Events and triggers¶

    Event Trigger
    endpoint_policy_added A new endpoint policy has been created.
    endpoint_policy_removed An existing endpoint policy has been deleted.
    endpoint_policy_updated A configuration item in a category (sub-policy) of an endpoint policy has been changed.
    endpoint_policy_updated_reverted A field in a category (sub-policy) of an endpoint policy has been reverted.
    endpoint_policy_enabled An endpoint policy has been enabled.
    endpoint_policy_disabled An endpoint policy has been disabled.
    endpoint_policy_group_changed The endpoint policy of a computer group has been changed to this policy.
    endpoint_policy_computer_changed The endpoint policy of a computer has been changed to this policy, either by specifying the policy or by following the group.
    endpoint_policy_override_created The endpoint policy overrides of a computer have been created.
    endpoint_policy_override_updated A configuration item in a category (sub-policy) of the endpoint policy overrides of a computer has been changed.
    endpoint_policy_override_updated_reverted A field in a category (sub-policy) of the endpoint policy overrides of a computer has been reverted.
    endpoint_policy_override_cleared The endpoint policy overrides of a computer have been cleared.

    Fields¶

    Field Value Explanation
    target String The name of the target endpoint policy; for the endpoint_policy_override_* events, the name of the target computer (or \<computer name>’s Endpoint Policy overrides).
    policy_platform Windows or Mac or Android The platform of the endpoint policy.
    sub_policy String The name of the category (sub-policy) of the endpoint policy that has been changed.
    \<config_item> (status, value) The configuration item that has been changed, with the field name as the property name and the updated status and value as the value.
    field String The name of the field that has been reverted.
    group String The name of the computer group whose endpoint policy has been changed.
    computer String The name of the computer whose endpoint policy has been changed.
    mode Specify a Policy or Follow Group How the endpoint policy of the computer has been assigned.

    Alert Profile¶

    Events and triggers¶

    Event Trigger
    alert_profile_added A new alert profile has been created.
    alert_profile_removed An existing alert profile has been deleted.
    alert_profile_updated A configuration item of an alert profile has been changed.
    alert_updated A configuration item of an alert in an alert profile has been changed.
    alert_profile_enabled An alert profile has been enabled.
    alert_profile_disabled An alert profile has been disabled.
    alert_profile_computer_assigned A computer has been assigned to an alert profile.
    alert_profile_computer_unassigned A computer has been unassigned from an alert profile.
    alert_profile_computer_autoassigned A computer has been automatically assigned to an alert profile by a deployment package.
    alert_profile_recipient_user_added A user has been added to the Email recipient list of an alert profile.
    alert_profile_recipient_user_removed A user has been removed from the Email recipient list of an alert profile.
    alert_profile_recipient_group_added A group has been added to the Email recipient list of an alert profile.
    alert_profile_recipient_group_removed A group has been removed from the Email recipient list of an alert profile.

    Fields¶

    Field Value Explanation
    target String The name of the target alert profile; for the alert_updated event, the name of the target alert.
    alert profile String The name of the alert profile that the alert belongs to. Present only in the alert_updated event.
    \<config_item> String The configuration item that has been changed, with the item name as the property name and the updated value as the value.
    computer String The name of the computer that has been assigned to or unassigned from the alert profile.
    deployment_package String The name of the deployment package that automatically assigned the computer to the alert profile.
    user String The account name of the user that has been added to or removed from the Email recipient list.
    group String The name of the group that has been added to or removed from the Email recipient list.
